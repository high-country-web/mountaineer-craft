# Server Plugins

Here are the plugins currently used on Mountaineer Craft and what they do.

| Plugin | Description |
| --- | --- |
| Back | Lets players return to a previous location, such as where they last died or teleported from. |
| Chunky | Pre-generates world chunks to help reduce lag when players explore new areas. |
| DiscordSRV | Connects the Minecraft server with Discord, including chat integration. |
| Essentials | Provides commonly used server commands and utility features. |
| EssentialsChat | Adds chat formatting and chat-related features for Essentials. |
| EssentialsSpawn | Manages the server spawn point and player spawn behavior. |
| floodgate | Lets Bedrock Edition players join the Java server through Geyser without needing a Java Edition account. |
| Geyser-Spigot | Allows Bedrock Edition players to connect to the Java Edition server. |
| GriefPrevention | Lets players protect their builds with land claims. |
| GrimAC | Detects and helps prevent cheating on the server. |
| GSit | Lets players sit, lay down, and use other simple poses. |
| InvSeePlusPlus | Allows authorized staff to inspect and manage player inventories and ender chests. |
| KeepChunks | Keeps selected chunks loaded when players are away. |
| LogCleaner | Automatically cleans up old server logs and crash reports. |
| LuckPerms | Manages player permissions, groups, and role inheritance. |
| Offlinetp | Lets staff teleport to an offline player's last known location. |
| Pl3xMap | Creates a browser-based map of the Minecraft world. |
| Pl3xMapExtras | Adds extra features to the Pl3xMap web map. |
| PlaceholderAPI | Provides placeholders that other plugins can use to display dynamic information. |
| Plan | Collects player and server activity analytics and presents them in a web interface. |
| Shopkeepers | Lets players create and use villager-based shops. |
| TAB | Customizes the player list, name tags, and related display elements. |
| Vault | Provides a common interface that lets economy, permissions, and chat plugins work together. |

# Discord Commands and Your Website Profile

The Mountaineer Craft Discord bot can show the server address, open the live map, and help you reach your website profile.

## Bot Commands

| Command          | What it does                                                                                        |
| ---------------- | --------------------------------------------------------------------------------------------------- |
| `/connect`       | Shows the Java and Bedrock server addresses.                                                        |
| `/map`           | Links to the [online server map](https://map.mountaineercraft.net/).                                |
| `/link`          | Opens your website profile and explains how to connect your Minecraft account.                      |
| `/whois @player` | Looks up available play information for a Discord member. This command is still a work in progress. |

## Open Your Website Profile

Use `/link` in Discord and select **Open your website profile**. Sign in with the same Discord account. If your Minecraft account is already linked, it will appear on your profile.

If you have not linked Minecraft yet, join the server and follow the existing verification process to submit your in-game code through Discord. After linking, use `/link` again to open your profile.

## Player Lookups

`/whois` can show available information such as a player's in-game status, deaths, sessions, join dates, and last-seen time. The command is still being developed, so some results may be unavailable. Its lookup uses the Discord member's server nickname when one is set; otherwise, it uses their Discord username.

For playtime analytics, visit [Plan analytics](https://analytics.mountaineercraft.net/register).

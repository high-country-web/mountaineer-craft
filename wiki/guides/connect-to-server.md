# Connect to the Server

Mountaineer Craft supports Java Edition and Bedrock Edition. Use the address for your edition when adding the server.

## Java Edition

Add a multiplayer server with this address:

`play.mountaineercraft.net`

## Bedrock Edition

Add an external server with these settings:

| Setting | Value                          |
| ------- | ------------------------------ |
| Address | `bedrock.mountaineercraft.net` |
| Port    | `19132`                        |

Bedrock players connect to the Java server through Geyser. In-game, Bedrock usernames have an asterisk (`*`) before them.

## If You Cannot Connect

- Check that you selected the address for your edition.
- For Bedrock Edition, make sure the port is set to `19132`.
- The server has a nightly restart at **12:15 AM Eastern Time** and is usually back online within five minutes.

The Discord bot's `/connect` command also shows the server addresses. See [Discord Commands and Your Website Profile](discord-and-website.md) for more bot commands.
